# Guarabira Educa

Extensão para o Google Chrome com melhorias para a plataforma Guarabira Educa do município de Guarabira - PB.

# Como instalar

Acessar a extensão na loja do Google Chrome:

- https://chromewebstore.google.com/detail/guarabira-educa/plccgpkejnhojjlehlmgokgekdnlimmh
