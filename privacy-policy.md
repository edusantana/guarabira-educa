# Privacy Policy — Guarabira Educa

_Last updated: 2026-05-20_

## Overview

Guarabira Educa is a Chrome extension that helps teachers in the municipality of Guarabira (PB, Brazil) work more efficiently with the Guarabira Educa educational platform at `guarabira-educa.ids.inf.br`.

## Data Collection and Use

This extension stores data **exclusively on the user's own device** using the Chrome built-in `chrome.storage.sync` API, which syncs data across the user's own Google account. Specifically, it stores:

- **`registrodiario`** — the content of the daily record form fields (Observações, Atividades Trabalhadas, Objeto de conhecimento/Conteúdos) that the user explicitly saves by clicking the "Copiar" button. This data is used solely to allow the user to paste the same content into other records on the platform.

## Data Sharing

We do **not** collect, transmit, sell, or share any user data with any third party. All data remains within the user's own Chrome storage.

## No External Servers

This extension does not communicate with any external server. No user data is sent outside the user's own browser and Google account sync.

## Limited Use

The use of any data handled by this extension complies with the [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/), including the Limited Use requirements. Data is used solely to provide the core functionality of the extension as described above.
